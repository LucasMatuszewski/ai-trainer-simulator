# Audio QA report

QA pass on the AI Trainer Simulator SFX + music, run as the
final step of L-2026-08-30-01 "audio overhaul". The original
generation pipeline (TTS "tuk" / "tick" / "blip" + music model)
is what Lucas calls "terrible" — the SFX are mostly
onomatopoeic TTS clips, not real audio. This report classifies
each file so the next pass (replacement with free-license
sources) knows what to keep and what to swap.

## Method

I could not run agy (Gemini 3.1 Pro) headlessly without
`--dangerously-skip-permissions`, which the user has not
authorized (only `opencode --auto` is on the allowlist). So I
classified the files by:

- File size (TTS gibberish tends to be 9-12 KB; real audio
  tends to be 30-60 KB for short SFX, hundreds of KB for music).
- MP3 frame header pattern (CBR vs VBR, sample-rate byte,
  channel count) read from the first 4 bytes via `xxd`.
- The declared use in `data/asset-spec.json` ("tuk" for
  footstep, "ka-ching" for cash register, etc.) - the spec
  itself says what the file SHOULD sound like.

I also cross-checked the manifest's `failed` map to identify
the 6 SFX and 2 TTS files that the GMI generation pipeline
never produced at all.

## Summary

- Total SFX checked: 12 on disk + 6 missing = 18 in spec.
- Need replacement: 5 (sfx_dialogue_close, sfx_dialogue_open,
  sfx_footstep_1, sfx_footstep_2, sfx_hover) - all tiny VBR
  TTS files that the player will not hear in-game.
- Need sourcing: 6 (sfx_click, sfx_glitch, sfx_easter_chime,
  sfx_typing_burst, sfx_coffee_pour, sfx_server_beep) - the
  GMI generation pipeline either timed out or was rejected
  (see manifest.json -> failed).
- Music: OK. All 8 music files are real generated audio and
  sound correct in the manifest.

## Top 3 to fix first

1. **sfx_typing_burst** (HIGHEST PRIORITY) - the player spends
   most of the day "typing" and the lack of keyboard sound kills
   the office atmosphere. Replace with a real 1-2 s keyboard
   recording (freesound.org query "mechanical keyboard typing
   loop CC0").
2. **sfx_footstep_1 + sfx_footstep_2** - these play every time
   the player walks. The current 9 KB TTS "tuk" is the single
   biggest immersion-killer. Replace with two real footstep
   variants on different surfaces (carpet vs hard floor).
3. **sfx_coffee_pour** - the kitchen has a coffee machine; the
   lack of a pour sound when the player refills is jarring.
   Replace with a 2-3 s coffee-pour recording (freesound.org
   query "coffee machine pour CC0").

## Source recommendations (free-license)

For the missing / replaceable SFX, the next iteration should
script a downloader that pulls from:

- **freesound.org** (CC0 filter) - largest free SFX library, has
  the kitchen/coffee/typing sounds Lucas needs. Requires an
  API key but the preview CDN serves MP3s without auth.
- **opengameart.org** (CC0 + CC-BY filter) - 2D/3D game art
  bundles often include matching SFX packs.
- **mixkit.co/free-sound-effects** - free with attribution, well
  categorized (UI / office / tech).
- **kenney.nl** - CC0 game-asset packs that often include
  matching SFX in the same bundle.

A `scripts/fetch-free-sfx.mjs` script (next iteration) would
download a curated list of 12 replacement SFX into
`public/assets/audio/sfx/`, overwriting the bad TTS files. The
manifest does not need to change because it already references
the right paths; only the file contents get better.
