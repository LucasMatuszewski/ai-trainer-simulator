# Brief for agy (Gemini 3.1 Pro): audio QA pass

## Context
You are reviewing the audio files for the AI Trainer Simulator
(3D IT-trainer sim, IT Crowd / Silicon Valley humor). The current
SFX were generated by a TTS model and are mostly short
onomatopoeia (e.g. "tuk", "tick", "blip") - the user (Lucas)
calls them "terrible" and we are replacing them with real audio
files. Music was generated by a music model and is fine.

## Inputs
Read `data/asset-spec.json` to see every SFX + music id and its
intended use. The current SFX are in `public/assets/audio/sfx/`
and the current music is in `public/assets/audio/music/`.

## Task
For each SFX file in `public/assets/audio/sfx/`, listen to it
(read the bytes; you do not need to decode the MP3 yourself,
the read tool will give you the file's contents or the path is
enough for you to confirm it exists and is non-empty).

1. Report whether the file is non-empty and at least 5 KB.
2. Give a one-line subjective description of what the file
   actually sounds like (e.g. "a low 'tuk' as expected for a
   footstep" or "silent / near-silent" or "a chime / ding for a
   notification"). Use the `sounds_like` field on the manifest
   meta if present; if not, describe what you can infer.
3. If the file is unsuitable for its declared use (silence, a
   wrong sound, way too short, or way too long), flag it as
   `needs_replacement: true` and write a one-line recommendation
   for what should replace it (e.g. "needs a real footstep
   thunk; try freesound id 246122 or a similar short low thunk").

## Output
Write your output to `.agent-briefs/agy-audio-qa-report.md`. Use
this exact format:

```
# Audio QA pass

## SFX
- sfx_footstep_1.mp3: <bytes> B, <description>, needs_replacement: <true|false>, <recommendation if true>
- sfx_footstep_2.mp3: ...
...
## Music
- music_title.mp3: <bytes> B, <description>
...
## Summary
- total SFX checked: N
- need replacement: M
- the 3 most urgent to fix (with the recommended replacement id or query)
```

Do not edit any source file. Do not commit. Do not push. Do not
read files larger than 1 MB unless the path is in the SFX or
music dir. Use the Read tool with the file path; it will give
you the metadata you need.
