## Findings

- **BLOCKER — repeated valid dodges never escalate.** `src/engine/agent-companion.ts:870-910`: `personDodgeStalls` increments only when `planDodgeAround` returns `null`. A returned dodge that is immediately blocked by the same stationary person resets `personHoldElapsed` but leaves `personDodgeStalls` at zero; the same dodge is installed forever, so the full `planRobotPath` replan is unreachable. A focused runtime probe with robot `(0,0)`, stationary NPC `(0,1.2)`, and room destination `(0,3)` reproduced this: after 500 updates at 0.1 s each, the robot remained at `(0,0.72)` with `walking: true` and `movingTo: north`. The temporary probe was removed after the run.
- **MAJOR — visible morning arrivals can materialize inside the robot.** `src/engine/npc-controller.ts:1274-1285`: `releaseArrival` assigns `arrival.door` directly and sets `visible = true`, without checking the live robot or `currentRobotBox`. If the robot is parked on that doorway lane, the NPC appears overlapping it before movement avoidance runs. `src/engine/agent-companion.ts:540-565` has the reciprocal case: joining always resets the robot to its fixed spawn without checking live NPC occupancy. The E2E test samples one robot route and a coffee-stop park, so it does not exercise either placement.
- **MAJOR — the dodge's furniture check is not a body-clearance check.** `src/engine/agent-companion.ts:90-105`: both legs are sampled against raw AABBs at 5% intervals. Unlike `planRobotPath` in `src/webmcp/robot-collision.ts:27-49`, it does not inflate boxes by the 0.3 m robot radius or use continuous segment intersection. A center line can pass outside an AABB while the body clips it; a thin wall can also fall between consecutive samples on a long leg. The current E2E assertion at `tests/e2e/ws9a-robot-collision.spec.ts:62-76` checks only that the robot center is not deep inside a box, so it would accept that clipping.
- **MINOR — the traversal prover does not verify continuous travel.** `tests/e2e/ws9a-robot-collision.spec.ts:222-265` keeps only each NPC's first position, last position, and minimum robot distance. It has no visible-state or maximum-per-sample-displacement check. The map is recreated after every `debugSkipPeriod`, which prevents a direct cross-window period-transition teleport from qualifying, but an in-window placement jump could still be counted as a traversal. Retain sampled segments and reject jumps before crediting a prover.

PHASE-VERDICT: FAIL — stationary blocker can trap the companion indefinitely; overlap and dodge-clearance paths remain unsafe.
